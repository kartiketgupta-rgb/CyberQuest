CORE CONCEPTS

Cybersecurity Fundamentals

Start with the concepts that every digital user should know.

01
🎣

Phishing

Phishing is a social engineering technique where attackers attempt to trick people into revealing sensitive information or performing unsafe actions.

  • Check suspicious links before opening them.
  • Be careful with unexpected emails and messages.
  • Never share passwords or OTPs through suspicious requests.
02
🦠

Malware

Malware refers to malicious software designed to disrupt, damage, monitor, or gain unauthorized access to systems.

  • Includes viruses, worms, trojans and spyware.
  • Avoid downloading software from untrusted sources.
  • Keep operating systems and security software updated.
03
🔒

Ransomware

Ransomware is a type of malware that can prevent access to files or systems and may demand payment from victims.

  • Maintain regular backups of important files.
  • Avoid suspicious attachments and downloads.
  • Keep security updates installed.
04
🔐

Password Security

Strong authentication helps protect accounts from unauthorized access.

  • Use unique passwords for important accounts.
  • Avoid easily guessed personal information.
  • Consider using a trusted password manager.
05
🛡️

Multi-Factor Authentication

MFA adds additional verification beyond a password, making unauthorized account access more difficult.

  • Enable MFA on important accounts.
  • Use authenticator applications when appropriate.
  • Never approve unexpected login requests.
06
🔥

Firewalls

A firewall helps control network traffic according to defined security rules.

  • Helps control incoming and outgoing traffic.
  • Can reduce unauthorized network access.
  • Should be configured and maintained appropriately.
07
🔑

Encryption

Encryption transforms readable information into protected data so that unauthorized parties cannot easily understand it.

  • Helps protect sensitive information.
  • Used in secure communications and online services.
  • Protects data both during transmission and storage.
08
🎭

Social Engineering

Social engineering manipulates people into revealing information or performing actions that may compromise security.

  • Attackers may use urgency or fear.
  • Verify unusual requests independently.
  • Do not trust messages only because they appear convincing.
09
🌐

Network Security

Network security focuses on protecting devices, systems, communications, and network resources from unauthorized access.

  • Use secure networks whenever possible.
  • Protect routers and network devices.
  • Monitor unusual network activity.
10
🌐

Web Security

Web security involves protecting websites, web applications, users, and data from common application-level threats.

  • Validate and protect user input.
  • Use secure authentication practices.
  • Keep frameworks and dependencies updated.
